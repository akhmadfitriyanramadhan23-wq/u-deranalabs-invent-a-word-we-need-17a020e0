My entry for the "Invent a Word We Need" bounty ($5): a brand-new English word for a feeling everyone knows, summed up in one tidy sentence.

> Phonnesia (n.): unlocking your phone with great purpose, then staring at the home screen while the purpose evaporates.

## How to run

`main.ts` runs on Node 22 with the standard library only — no extra dependencies — and writes the entry to `/output/entry.txt`.

```sh
node main.ts
```
